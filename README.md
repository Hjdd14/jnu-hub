## ✨ 为什么做这个 App

暨大的线上服务分散在多个系统里：教务一个、水电一个、体测又是另一个，
每个都要单独登录、单独记住域名、单独在手机浏览器里缩放拖拽。

**暨大通**把它们整合成一个原生 App：

- 🎯 **原生界面** —— 不是套壳网页，课表能左右切周、成绩能按学期折叠、图表能点选读数
- 🔑 **一次登录** —— 统一认证登录后，各系统自动同步会话，剩余有效期首页实时可见
- 💾 **离线可读** —— 数据本地缓存，断网也能翻看课表和成绩，下拉才重新拉取
- 🌙 **深色优先** —— 全程 Material 3 深色主题，夜间看不刺眼

## 🖼 界面预览

> 出于隐私考虑，仓库内不附带真实数据截图。
> 界面采用 Material 3 深色主题，卡片式分区，底部五栏导航：
> **首页 · 学业 · 课程 · 服务 · 我的**

### 视觉特征

| 设计点 | 做法 |
|:---|:---|
| 配色 | 深色底 + 高饱和主题色点缀，按服务类型区分图标色 |
| 层级 | 每屏一个主任务，卡片分组，避免堆叠 |
| 反馈 | 加载有骨架屏，失败有可重试的错误态，缓存标注「数据更新于 X 分钟前」 |
| 手势 | 图表点按 / 拖动读数，课表左右滑动切周，长按刷新可重置直连探测 |

## 🚀 开始使用

### 环境要求

| 项目 | 要求 |
|:---|:---|
| Android | 8.0（API 26）及以上 |
| 网络 | **需连接校园网或学校 VPN**（校内域名不对外网开放） |
| 账号 | 暨大统一身份认证（jAccount） |

### 构建

```bash
git clone <your-repo-url>
cd jnu-app
./gradlew assembleDebug
```

产物位于 `app/build/outputs/apk/debug/app-debug.apk`。

> 需要本地配置 `local.properties` 指向 Android SDK（该文件不入库）。

### 首次使用

1. 启动 App，进入「我的 → 登录」
2. 完成滑块验证与账号密码登录
3. 返回首页，各系统会话会自动同步
4. 水电首次使用需「同步水电账号」或手动填写户号（在宿舍水表 / 电表卡上可见）

## ❓ 常见问题

<details>
<summary><b>首页余额显示「--」怎么办？</b></summary>

水电余额需要先建立一次水电系统会话。进入「水电查询」，按提示同步账号或填写户号（以 `T` 开头）即可。

</details>

<details>
<summary><b>提示「无法连接水电系统」？</b></summary>

校内域名（`jnu.edu.cn` 系列）只对校园网与学校 VPN 开放。请切换网络后重试。

</details>

<details>
<summary><b>体测登录失败？</b></summary>

体测使用**独立账号体系**，与统一认证无关：

- 账号：学号
- 初始密码：8 位生日数字（如 `20050101`）
- 若忘记密码，请在浏览器打开体测系统用「找回密码」重置

</details>

<details>
<summary><b>体测成绩显示「暂未开放查询」？</b></summary>

这是体测系统的原始返回，通常表示该学年成绩尚未录入。可以切换年份查看往年成绩。

</details>

<details>
<summary><b>为什么有些数据是旧的？</b></summary>

为减少请求，数据会缓存并标注更新时间。点右上角刷新可强制重新拉取。

</details>
